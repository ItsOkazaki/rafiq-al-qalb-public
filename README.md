## الفكرة

رفيق القلوب ليس محرك إجابات مفتوحاً. هو سير بحث موجّه بالمصادر:

1. يستقبل سؤالاً أو وصفاً بحثياً باللغة العربية.
2. يطبّع الصياغة ويحدد الأبواب البحثية ذات الصلة.
3. يسترجع مقاطع من المكتبة المعتمدة فقط.
4. يعرض المصدر والموضع والرابط الأصلي لكل مادة مسترجعة.
5. عند تفعيل مزود الذكاء الاصطناعي، ينظّم المقاطع المسترجعة فقط بدلاً من التوليد من معرفة مفتوحة.
6. عند غياب مادة كافية، يستخدم الامتناع الواضح بدلاً من التخمين.

## ما الذي يميزه؟

### Evidence-Grounded Retrieval

الاسترجاع محصور في corpus معروف وسجل مصادر صريح، مع إزالة النتائج من المصادر غير المسموح بها.

### Faithful Abstention

عدم وجود دليل كافٍ ليس خطأً يجب إخفاؤه. النظام يعرض عدم كفاية المادة بدلاً من ملء الفراغ بمعلومة غير موثقة.

### Arabic-first NLP

المعالجة الحالية تتضمن تطبيع العربية، إزالة التطويل والتشكيل عند الحاجة، توحيد بعض الصيغ العامية، واستخراج كلمات مفتاحية مناسبة للمكتبة الحالية.

### Safety and scope controls

قبل الاسترجاع توجد فحوصات للسلامة، وطلبات الفتوى، والطلبات ذات الطابع الوصفي الشخصي. الهدف هو إبقاء المنتج في نطاق البحث والعرض الموثق، لا إصدار أحكام أو تشخيصات شخصية.

## المصادر الحالية

المكتبة الحالية تشمل مواد محددة من مصادر معروفة، مع بيانات المصدر والموضع والرابط في `src/lib/sources/registry.ts` و`src/lib/corpus/`.

**مهم:** قبل النشر العام أو إعادة توزيع corpus، راجع حقوق استخدام كل مادة في سياق المشروع الذي ستنشره فيه.

## البنية التقنية

- **Frontend / App:** Next.js 16 + React 19 + App Router
- **Arabic text processing:** TypeScript utilities in `src/lib/text/`
- **RAG:** topic matching + keyword retrieval in `src/lib/rag/`
- **Corpus:** local indexed passages in `src/lib/corpus/`
- **Source registry:** `src/lib/sources/`
- **Policy / safety:** `src/lib/policy/` and `src/lib/safety.ts`
- **AI layer:** grounded provider in `src/lib/ai/provider.ts`
- **Research orchestration:** `src/lib/research/pipeline.ts`
- **Deployment:** any Node-compatible host, including Vercel

## تشغيل المشروع محلياً

### المتطلبات

- Node.js 18+
- npm

### التثبيت

```bash
git clone https://github.com/YOUR_USERNAME/rafiq-alqulub.git
cd rafiq-alqulub
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

### تشغيل طبقة الذكاء الاصطناعي

انسخ `.env.example` إلى `.env` وأضف مفتاحك **محلياً فقط**:

```bash
cp .env.example .env
```

لا تضع مفتاحاً حقيقياً داخل GitHub أو داخل الكود.

## مساهمة الفريق

التطوير الجماعي مرحب به. للحفاظ على حدود المشروع:

- اجعل تغييرات الـ UI في `src/app` و`src/components`.
- اجعل تغييرات اللغة العربية في `src/lib/text`.
- اجعل تغييرات الاسترجاع في `src/lib/rag`.
- اجعل تغييرات الذكاء الاصطناعي في `src/lib/ai` مع إبقاء الأدلة المسترجعة هي مصدر الحقائق.
- لا تضف أسراراً أو مفاتيح API إلى المستودع.
- عند إضافة مصدر جديد، حدّث سجل المصدر والمادة المفهرسة وراجع حقوق الاستخدام أولاً.

راجع `CONTRIBUTING.md` لمعيار العمل بالفروع وPull Requests.

## الخطة التالية

المرحلة التالية المقترحة للفريق هي جعل طبقة الذكاء الاصطناعي جزءاً أكبر من سير البحث نفسه، مثل التخطيط الذكي للاستعلام، الاسترجاع الدلالي العربي، إعادة ترتيب المقاطع، والتحقق على مستوى الادعاء، مع الإبقاء على بوابة الأدلة والامتناع كضوابط ثابتة.
