# خريطة الموقع — رفيق القلوب (Sitemap)

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | الصفحة الرئيسية |
| `/hiwar` | الحوار والبحث |
| `/hala` | الاستبانة |
| `/maktaba` | المكتبة المعتمدة |
| `/maktaba/[bab]` | صفحة الباب |
| `/maktaba/kutub/[slug]` | صفحة المصدر |
| `/wasfa` | صفحة توضيحية للميزة المتوقفة |

## المسارات المساعدة

| المسار | الوظيفة |
|---|---|
| `/api/research` | تنفيذ البحث |
| `/api/health` | فحص حالة الخدمة |

## العلاقات

- الرئيسية تقود إلى الحوار والاستبانة والمكتبة.
- نتائج الحوار ترتبط بالأبواب والمصادر.
- صفحات الأبواب ترتبط بالمصادر والأسئلة ذات الصلة.
- صفحات المصادر تربط بالمصدر الأصلي عند توفره.
